# Sealed Bid Register

本地竞价演练登记工具。仅使用 Go 标准库，不连接任何支付或交易平台。

## 运行

```sh
go run ./cmd/auction --state 状态目录
```

程序从标准输入逐行读取 JSON 命令，每条命令输出一行 JSON 响应
（`{"ok":true,"data":...}` 或 `{"ok":false,"error":"..."}`）。
状态保存在状态目录的 `state.json` 中，退出后重开自动恢复。

## 命令

| 命令 | 说明 |
| --- | --- |
| `{"cmd":"create","auction":"A1","reserve":100}` | 创建拍卖，保留价为非负整数分 |
| `{"cmd":"commit","auction":"A1","bidder":"alice","commitment":"<hex>"}` | 提交承诺（仅承诺阶段，每人一次） |
| `{"cmd":"open_reveal","auction":"A1"}` | 从承诺阶段切换到揭示阶段 |
| `{"cmd":"reveal","auction":"A1","bidder":"alice","amount":500,"nonce":"n1"}` | 揭示报价（仅揭示阶段） |
| `{"cmd":"query","auction":"A1"}` | 查询拍卖状态 |
| `{"cmd":"settle","auction":"A1"}` | 结算并进入结算阶段 |

阶段只能沿 `commit → reveal → settled` 前进。错误命令不会改变已有记录。

## 承诺计算

承诺是对以下字符串（UTF-8 编码）的 SHA256，取小写十六进制（64 字符）：

```
拍卖号|竞买人号|报价|随机串
```

- 拍卖号、竞买人号、随机串：非空，仅含 ASCII 字母或数字。
- 报价：非负整数十进制，无前导零（与 JSON 中的 `amount` 一致）。
- 四项以竖线 `|` 连接，例如 `A1|alice|500|n1`。

## 揭示与查询

- 揭示时重新计算承诺，匹配才记录有效报价。
- 随机串或金额错误不消耗揭示机会，可重试；成功揭示后不可更改。
- 结算前 `query` 只公开各竞买人的承诺与是否已揭示，不输出报价或随机串。

## 结算规则

- 只考虑有效揭示的报价；最高报价达到保留价才成交，否则流拍。
- 同价时取竞买人号字典序最小者。
- 成交价为保留价与其余有效报价最高值的较大者；无其他报价时取保留价。
- 结算后公开所有有效报价与未揭示名单；重复 `settle` 返回相同结果。

## 测试

```sh
go test ./...
```

覆盖同价结算、失败揭示后重试、阶段约束、保留价规则与重开后状态恢复。
